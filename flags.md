# SCRIPT FLAGS
This page will contain all flags used in the script, and their basic explanations.

All flags are beginning with the symbol "-", and are removed during the flag step during the script (unless, for example, ignored)
## General flags
* **-q** - quit flag. Sets the script into the "quit mode", and stops the flag step.
* **-d** - debug flag. Toggles Debug mode for this cycle of the script.
* **-dp** - debug persistent flag. Toggles Debug mode for all cycles of the script. Will overwrite -d flags that were checked before -dp flag.

## Translation mode flags
* **--** - skip word flag. Skips next word in translation mode.
* **-d (-dp)** - debug (persistent) flag. Shows advanced translation step outputs.
